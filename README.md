# Tale (Android NAS 客户端)

> **“由于目前没有找到很好的安卓原生类似飞牛的 APP 应用管理工具，所以我直接手搓了一个，也就是这个 TALE APP。”**

Tale 是一款专为私有云存储和 WebDAV 打造的安卓原生 NAS 客户端。

市面上现有的工具要么是套壳网页卡顿严重，要么缺乏针对移动端相册和日常文件管理的人机交互设计。为了满足自己随时浏览相册、自动备份照片、在线看片以及跨设备管理服务器文件的需求，我写了这个 App，现在完整开源出来供大家使用。

---

## 📱 核心功能与实现

### 1. 相册与时间线浏览
- **本地与云端双源融合**：即使新拍的照片还没来得及上传到 NAS，手机相册里的本地照片也会实时呈现，无需等待备份即可浏览。
- **真实时间线排列**：按照真实的拍摄时间戳严格倒序排列，划分为“今天”、“昨天”和具体日期。
- **智能悬浮年份飞梭**：当快速向下滑动浏览较早的历史照片时，屏幕右侧会自动滑出半透明毛玻璃年份条，点击年份即可瞬间直达。
- **沉浸式浏览模式**：相册向上滑动看图时，会自动连同安卓系统顶部状态栏（时间、电池、信号等）一起收纳隐藏；向下滑动时自适应恢复。
- **纯粹相片管理**：相册内严格排除了视频文件，视频统一交由独立的媒体库管理，互不干扰。

### 2. 双向同步与多端文件管理
- **后台自动备份**：支持将手机本地相册或指定文件夹自动同步至云端 NAS，下拉刷新即可在顶部留白处直观看到同步进度。
- **多端联动操作**：在手机端删除照片时，支持同时物理删除本地照片与云端 NAS 存储，避免两头重复清理。
- **自定义文件夹双向同步**：通过 Android 原生存储访问框架（SAF），可将手机任意目录与 NAS 目录进行双向或单向绑定同步。

### 3. 在线媒体播放与文件管理
- **在线音视频流畅播放**：内置媒体播放器，支持 WebDAV 断点续传与切片推流，拖动进度条不黑屏。
- **多端点测速与容错**：支持配置多个服务地址（公网域名、局域网 IP），连接时自动探活并选择最优线路，遇 502/网络抖动具备自动重试机制。

## 📦 下载与安装

已编译并签名的安装包可直接获取：

- **APK 预编译安装包**：仓库根目录下的 [`apk/Tale-v1.2.2-release.apk`](apk/Tale-v1.2.2-release.apk)（或前往 GitHub Releases 页面下载）。
- 下载后传到安卓手机上直接点击安装即可使用。

## 🛠️ 开发者本地构建（可选）

如果你想二次开发或自己修改代码打包：

1. 克隆本仓库：
   ```bash
   git clone https://github.com/maoleidiss/tale-android.git
   cd tale-android/android_project
   ```
2. 使用 Android Studio 打开 `android_project` 目录，或者直接通过 Gradle 命令行构建：
   ```bash
   ./gradlew assembleRelease
   ```
   构建生成的 APK 文件位于 `app/build/outputs/apk/release/`。
